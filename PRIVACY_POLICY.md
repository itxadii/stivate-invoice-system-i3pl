# Privacy Policy

**Offline Warehouse Dispatch Management Software**

**Effective Date:** 10 August 2026  
**Version:** 1.0  
**Provider:** Stivate  
**Software:** Warehouse Dispatch Management Software  

---

## 1. Introduction

This Privacy Policy explains how Stivate handles information processed through the Offline Warehouse Dispatch Management Software ("Software").

The Software is designed primarily as an offline Windows application. Operational data is stored locally on the customer's computer. Certain services, such as automated cloud backups, software updates, and support requests, may require an internet connection.

We aim to collect and process only information necessary to provide, maintain, secure, back up, and improve the Software.

---

## 2. Information Processed by the Software

Depending on how the customer uses the Software, the following information may be stored:

### Dispatch Information
- Dispatch Challan number
- Dispatch date
- Vehicle number
- Supervisor name
- Scanner/operator name
- Verifier name
- Consignee information
- Address
- Pallet information
- Transaction information
- Particulars
- Dispatch status

### Pull List Information
- Pull List number
- ID/reference number
- Kit information
- Workcell information
- Parts quantity
- Barcode information

### Operational Information
- Creation and modification timestamps
- Dispatch status
- Printing records where applicable
- Application configuration
- Audit information where enabled

### Technical Information
The Software may process limited technical information such as:
- Application version
- Operating system information
- Installation information
- Error/log information

Such information is used for troubleshooting, updates and software support where applicable.

---

## 3. Offline Data Processing

The Software is designed to operate without an active internet connection.

Operational dispatch information is primarily stored on the customer's local computer.

Internet connectivity is not required for normal dispatch operations.

The Software should continue to allow the customer to:
- Create dispatches
- Scan Pull Lists
- Edit dispatches
- Print documents
- View history
- Generate reports

when the computer is offline.

---

## 4. Cloud Backup

The Software may automatically create cloud backups of the local application database.

Cloud backup is intended to protect the customer's operational information against:
- Computer failure
- Database corruption
- Accidental deletion
- Hardware failure
- Local data loss

Cloud backups may contain the same operational information stored in the application's local database.

Cloud backup is performed only for the purpose of data protection and recovery.

Cloud backup failure should not prevent the Software from operating offline.

---

## 5. Cloud Storage

Cloud backups may be stored using a third-party cloud infrastructure provider selected by Stivate or agreed with the customer.

The applicable cloud provider may process and store encrypted backup data on behalf of the Software provider/customer.

Access to cloud storage should be restricted to authorized personnel and systems.

Stivate should not use customer dispatch data for advertising, selling data, profiling employees, or unrelated commercial purposes.

---

## 6. Software Updates

The Software may periodically check for available software updates.

Update checks may communicate limited technical information necessary to determine whether a newer version is available.

Software updates may be distributed through a third-party software distribution service.

Updates are intended to provide:
- Bug fixes
- Security fixes
- Performance improvements
- New functionality
- Compatibility improvements

The application should not transmit customer dispatch data merely to check for software updates.

---

## 7. Support Requests

If the Software includes a support or feature-request facility, information voluntarily submitted by the user may include:
- Company name
- Application version
- Feature request
- Bug description
- Contact information
- Technical information voluntarily included by the user

Users should not submit passwords, authentication credentials, financial information, or unrelated sensitive personal information through the support form.

## 8. Purpose of Processing

Information processed by the Software may be used for:
- Creating and managing dispatch records.
- Generating delivery challans.
- Managing Pull Lists.
- Generating operational reports.
- Maintaining dispatch history.
- Providing backup and restoration.
- Providing technical support.
- Diagnosing software errors.
- Providing software updates.
- Maintaining application security.

We do not intend to use customer operational data for unrelated purposes.

---

## 9. Data Sharing

Stivate does not sell customer operational data.

Information may be accessible to:
- Authorized customer personnel
- Authorized Stivate support personnel
- Cloud infrastructure providers used for backup
- Software distribution/update providers where technically required
- Other service providers necessary to operate the Software

Third-party service providers should only receive information necessary for the relevant service.

---

## 10. Data Retention

Local dispatch data remains under the control of the customer and is retained according to the customer's operational requirements.

Cloud backups may be retained according to the backup retention configuration agreed with the customer.

When cloud backups are no longer required, they should be deleted according to the applicable retention policy.

Customers remain responsible for determining how long business records must legally or operationally be retained.

---

## 11. Data Deletion

Because the Software is primarily offline, the customer controls the local database stored on the customer's computer.

Deletion of local application data may be performed by an authorized customer administrator.

Cloud backup deletion may require authorized access to the configured cloud backup system or assistance from Stivate.

Deleting a local database does not necessarily mean that historical cloud backups are immediately deleted.

---

## 12. Data Accuracy

Customers are responsible for ensuring that information entered into the Software is accurate.

The Software provides tools intended to reduce manual errors but cannot guarantee that manually entered business information is correct.

## 13. Security

Stivate takes reasonable technical and organizational measures to protect customer information against unauthorized access, alteration, disclosure, loss, and destruction.

Security measures may include:
- Restricted access
- Local database protection
